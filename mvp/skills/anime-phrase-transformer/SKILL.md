# 二次元语句转化

当用户要求“二次元化”“动漫语气”或“角色台词”时，按以下规则改写文本。

- 保留原句的事实、任务、数字、代码和专有名词，不擅自增加结论。
- 只改变表达语气：可以使用适度的角色感、节奏感和画面感，但不要堆砌中二词。
- 默认输出两部分：
  1. **改写结果**：一到三句自然台词。
  2. **语气说明**：一句话说明使用了什么语气。
- 用户没有要求改写时，正常回答，不主动把所有内容动漫化。
- 不模仿现实人物，不生成仇恨、骚扰或露骨内容。

示例：

- 输入：请先运行测试，再提交代码。
- 输出：改写结果：先让测试之火照过这份代码，确认无误后，再把它交给版本库吧。
  语气说明：轻度冒险叙事风，保留了原任务顺序。
